# 📖 Руководство для опекунов и семьи (v0.8.5)

**🌐 Язык:** [English](DOCS_ADMIN.md) · **Русский** · [Nederlands](DOCS_BEHEERDER_NL.md)

Добро пожаловать в Senioren Launcher. Это руководство предназначено для членов семьи, опекунов и администраторов. Лаунчер полностью готов к **Android 16 (Baklava)** и соответствует строгому европейскому законодательству о защите данных (**GDPR**).

---

## 🛠️ 0. Первая установка (мастер настройки)
1.  **Выберите язык:** самый первый экран предлагает выбрать язык (Русский, Nederlands, ...). По умолчанию выбран русский. Позже язык можно изменить в разделе *«Настройки»*.
2.  **Примите заявление о конфиденциальности.**
3.  **Выберите роль:** *«Я опекун»* (техническая настройка) или *«Я пользователь»* (личный выбор пожилого человека).
4.  **Шаги для опекуна:** разрешения, системные разрешения, приложения по умолчанию (главный экран, телефон, SMS), основные контакты (до 4, они становятся избранными и SOS-контактами), обнаружение падения, PIN-код и удалённая помощь.
5.  **Передайте телефон пожилому человеку** — он выберет размер текста и цвета.

> **Совет:** все экраны настройки прокручиваются, а кнопка «Далее» остаётся внизу экрана даже при самом большом размере текста.

## 🔐 1. Авторизация: как стать администратором
Чтобы управлять телефоном удалённо, Ваш номер должен быть распознан как авторизованный SOS-контакт.

### Пошаговая инструкция:
1.  **Откройте «Контакты»:** на экране пожилого человека нажмите кнопку **«Контакты»**.
2.  **Добавьте контакт:** добавьте себя (или отредактируйте существующий контакт).
3.  **Отметка звёздочкой:** убедитесь, что Вы отмечены как **избранный / SOS-контакт** (обычно нажатием на звёздочку рядом с именем).
4.  **Распознавание номера:** введите свой номер. Приложение автоматически распознаёт все форматы:
    *   Локальный: `0487123456`
    *   Международный: `+32487123456` или `0032487123456`
5.  **Проверка:** отправьте со своего телефона SMS с текстом `#PING` на телефон пожилого человека. Если на его экране появилось подтверждение, связь установлена.

## 🏠 2. Настройка главного экрана
- **Сетка и размер текста:** *«Настройки»* (под PIN-кодом) → выберите 1x1, 2x3 или 3x4 и размер текста. Количество рядов плиток подстраивается под экран, поэтому ничего не обрезается. Лишние плитки переходят на страницы, которые можно листать (точки страниц под сеткой).
- **Изменение порядка плиток:** удерживайте плитку, затем сколько нужно раз нажимайте **«◀ Раньше»** или **«Позже ▶»** и в конце — **«ГОТОВО»**. В окне показано место плитки, например «Звонки: место 2 из 8».
- **Замена или удаление приложения:** в том же окне нажмите **«Заменить или убрать»** (для «Настроек», Wi-Fi и Bluetooth недоступно).
- **Язык:** *«Настройки»* → Язык. Приложение перезапустится и покажет новый язык.
- **Большие часы:** нажмите на время вверху главного экрана, чтобы увидеть время и дату очень крупно. Нажмите в любом месте, чтобы закрыть.

### 🔑 PIN-код настроек
- **PIN-код по умолчанию: `1234`.** Свой PIN можно задать в мастере настройки (шаги для опекуна). До этого действует `1234`.
- **Блокировка:** меню запрашивает PIN только после нажатия **«Заблокировать меню»** внизу *«Настроек»*.
- **Смена удалённо:** отправьте с SOS-контакта SMS `#PIN 5678` (см. [COMMANDS_RU.md](COMMANDS_RU.md)).
- **Забыли PIN:** отправьте `#PIN` с новым кодом с SOS-контакта или переустановите приложение (все настройки будут сброшены).

### 💬 Telegram (сообщения и звонки)
Telegram встроен в лаунчер, поэтому пожилому человеку не нужно осваивать приложение Telegram. Чаты Telegram показываются в **«Сообщениях»** рядом с SMS, а звонки Telegram идут через собственный крупный экран звонка лаунчера.

**Подключение (один раз):**
1. Откройте **«Сообщения»** → **«Подключить Telegram»**.
2. Проверьте номер телефона и нажмите **«Отправить код»**. Код приходит по SMS и **вводится автоматически**. Если Telegram отправит код на другое устройство, где уже выполнен вход, введите его вручную.
3. Если у аккаунта есть пароль Telegram (двухэтапная аутентификация), введите его.
- **Проще с помощником:** нажмите **«Пусть помощник отсканирует код»**. На своём телефоне откройте Telegram → *Настройки* → *Устройства* → **Подключить устройство** и отсканируйте код на телефоне пожилого человека.
- На этот номер уже должен быть зарегистрирован аккаунт Telegram. Если нет, сначала создайте его в приложении Telegram.
- Если кнопки нет, эта сборка приложения сделана без Telegram (см. [TELEGRAM.md](TELEGRAM.md)).

**Звонки:**
- Откройте чат Telegram и нажмите большую зелёную кнопку **«Позвонить»** вверху или синюю кнопку с **камерой** рядом для **видеозвонка**. В первый раз Android спросит разрешение на микрофон (и камеру): разрешите, иначе собеседник не услышит и не увидит.
- Во время звонка: громкая связь, микрофон (выключить звук), **«Включить камеру»** и кнопка «положить трубку». Экран гаснет, когда телефон поднесён к уху.
- **Видеозвонки:** собеседник занимает весь экран, собственное изображение маленькое в углу, его можно перетащить пальцем. Кнопки: камера вкл/выкл, **«Другая камера»** (передняя/задняя), громкая связь, микрофон, «положить трубку». Панель кнопок сворачивается ручкой над ней (или касанием видео); кнопка «положить трубку» видна всегда. Видеозвонки начинаются на громкой связи.
- **Входящие звонки Telegram** звучат обычной мелодией звонка и открывают полноэкранный экран с кнопками **«Ответить» / «Отклонить»**, в том числе на заблокированном экране.
- Звонки Telegram защищены сквозным шифрованием.

**Telegram для обычных звонков:** *«Настройки»* → **«Звонки»**: **«Звонить через Telegram за границу»** (включено по умолчанию) и **«Звонить через Telegram всегда»**. Когда пожилой человек звонит на номер с экрана «Телефон», звонок идёт через Telegram (внутри лаунчера), если у контакта есть Telegram; если нет — пробуется официальное приложение Telegram, иначе выполняется обычный звонок. Экстренные и другие короткие номера всегда идут через телефонную сеть.

**Нет SIM-карты:** звонки с экрана «Телефон» автоматически идут через Telegram. Если у контакта нет Telegram, появится сообщение, что позвонить нельзя. Экстренные номера (112/911) работают и без SIM-карты.

**Пока не поддерживается:** фото, голосовые сообщения и файлы показываются как «[Фото или файл]»; групповые чаты пока не отображаются.

**Отключение:** «Сообщения» → Telegram → **«Отключить Telegram»**. Выполняется выход, а данные Telegram на телефоне удаляются.

### 🆘 SOS: чтобы помощь точно пришла
Когда пожилой человек нажимает SOS (или обнаружено падение):
1. **Сообщения:** каждый контакт SOS получает SMS с местоположением. Тем, до кого SMS не дошло (нет SIM-карты или отправка не удалась), то же сообщение уходит через **Telegram**. На экране: «Сигнал отправлен: SMS — X, Telegram — Y».
2. **Звонки:** телефон по очереди звонит контактам SOS на громкой связи, пока кто-нибудь не поговорит с пожилым человеком около 25 секунд (не более 3 кругов). Без SIM-карты это звонки Telegram. Кнопка **«Я в безопасности»** останавливает звонки.
3. **Беззвучный режим не мешает:** во время экстренной ситуации телефон выключает беззвучный режим и «Не беспокоить» и ставит громкость звонка, разговора и будильника на максимум, чтобы ответный звонок был слышен. Прежние настройки возвращаются после «Я в безопасности» или через 30 минут. То же происходит при наборе экстренного номера.
4. **Если ничего не дошло** (нет SIM, нет интернета, нет контактов SOS…), красный экран сообщает **«ПОМОЩЬ НЕ ПРИДЁТ»**, указывает причину и даёт большую кнопку вызова **112/911**, который работает даже без SIM-карты.

**Для контактов SOS (опекунов): чтобы пожилой человек дозвонился, даже если ваш телефон на беззвучном.**
- **iPhone:** Контакты → пожилой человек → Править → Рингтон → включите **«Обход в экстренных ситуациях»** (то же для «Звука сообщения»).
- **Android:** добавьте контакт в избранное, затем в «Не беспокоить» разрешите вызовы и сообщения от **избранных контактов** и включите **повторные вызовы**. SOS перезванивает в течение нескольких минут, поэтому «повторные вызовы» пропускают звонок.
- **Сигнал для опекуна:** установите Senioren Launcher и на свой телефон (делать его главным экраном не нужно — достаточно один раз открыть и разрешить SMS). Каждое сообщение SOS начинается с 🆘; когда оно приходит, ваш телефон подаёт **громкий сигнал** даже в беззвучном режиме, с кнопками **«Перезвонить»**, **«Открыть карту»** и **«Выключить сигнал»**.

**Нужные разрешения** (большинство запрашивает мастер настройки): доступ к режиму «Не беспокоить» (*Настройки → Приложения → Специальный доступ → Доступ к «Не беспокоить» → Senioren Launcher*), доступ к уведомлениям, а на телефонах **Xiaomi/Redmi/POCO** — **Автозапуск** для лаунчера (*Настройки → Приложения → Все приложения → Senioren Launcher → Автозапуск*). Без автозапуска MIUI блокирует службу уведомлений: тогда «Очистить всё» и скрытие баннера звонка приложения Telegram не работают.

### 🔔 Уведомления и кнопка «Назад»
- **«Очистить всё»** на экране уведомлений также отмечает чаты в Telegram, WhatsApp и подобных приложениях как прочитанные, чтобы уведомления не появлялись снова.
- **Стрелка «Назад»** вверху каждого экрана ведёт сразу на главный экран.

### 🔄 Передача телефона новому владельцу
- *«Настройки»* → Система → **«Начать настройку заново после перезагрузки»**. После следующей перезагрузки мастер настройки запустится снова (один раз). Сохранённый собственный номер сбрасывается; контакты, лекарства и будильники остаются. При необходимости отключите Telegram в «Сообщениях» вручную.

## 📱 3. Конфиденциальность и безопасность (готово к Android 16)
Приложение построено по принципу **Privacy by Design**. Это значит:
*   **Метки конфиденциальности:** на экранах, где используются чувствительные данные (например, местоположение или контакты), пожилой человек теперь видит синий значок конфиденциальности с понятным объяснением, зачем нужны эти данные.
*   **Безопасные обновления:** лаунчер раз в день проверяет, есть ли новая версия. Если есть, появляется уведомление **«Доступна новая версия …»** с кратким списком изменений. Ничего не загружается, пока на него не нажать; затем обновление скачивается по HTTPS, и Android предлагает его установить.
*   **Защита от мошенников:** лаунчер автоматически блокирует известные спам-номера и предупреждает о подозрительных SMS.

## 🎮 4. Удалённое управление по SMS (полный список)
Отправьте пожилому человеку SMS с одним из следующих кодов. Приложение отреагирует сразу. Коды всегда на нидерландском, независимо от языка приложения (полный список с пояснениями — в [COMMANDS_RU.md](COMMANDS_RU.md)).

| Категория | Код | Действие |
|:----------|:-----|:------|
| **Самочувствие** | `#WAAR` | Получить GPS-координаты в виде ссылки Google Maps. |
| | `#STATUS` | Проверить заряд батареи, уровень сигнала и громкость. |
| | `#PING` | Показать на экране крупными буквами «ALLES GOED?» («Всё в порядке?»). |
| | `#BEL_TERUG` | Телефон сразу перезванивает Вам. |
| **Помощь** | `#LAMP AAN` / `#LAMP UIT` | Включить / выключить фонарик удалённо. |
| | `#KNIPPER` | Заставить фонарик мигнуть 10 раз (чтобы найти телефон). |
| | `#ALARM [текст]` | Включить громкий сигнал с сообщением. |
| **Настройки** | `#VOLUME [1-15]` | Изменить громкость звонка (например, `#VOLUME 15`). |
| | `#HELDER [1-100]` | Изменить яркость экрана. |
| | `#WIFI AAN` / `#WIFI UIT` | Управлять подключением к интернету. |
| | `#STIL AAN` / `#STIL UIT` | Включить / выключить беззвучный режим («Не беспокоить»). |
| **Управление** | `#PRIVACY` | Получить обзор настроек конфиденциальности. |
| | `#UPDATE_CHECK` | Принудительно проверить наличие обновлений приложения. |
| | `#RESTART` | Перезапустить приложение-лаунчер. |
| | `#THEMA [1, 2 или 3]` | Сменить тему (1 — классическая, 2 — высокий контраст, 3 — светлая). |

## ❓ Часто задаваемые вопросы (FAQ)

**В: Почему телефон не реагирует на мои SMS?**
*   Проверьте, что Ваш номер есть в списке контактов со звёздочкой (SOS).
*   Убедитесь, что у пожилого человека есть средства на счёте для отправки ответного SMS.

**В: Можно ли назначить нескольких администраторов?**
*Да, любой контакт, отмеченный как SOS/избранный, может использовать команды.*

**В: Насколько точно определяется местоположение?**
*Приложение использует GPS. Если человек находится в помещении, точность может быть ниже. В SMS всегда указана ориентировочная погрешность в метрах.*

**В: Текст слишком крупный, и я не могу найти кнопку.**
*Экраны прокручиваются, а на главном экране при более крупном тексте показывается меньше рядов; листайте вбок, чтобы увидеть остальные плитки. Если текст всё равно слишком крупный, уменьшите размер текста в настройках или отправьте `#LETTER 3`.*
